# 2026-09-20 추가 확정 사항 — 배당 추정을 진짜 배당 데이터(KIS 예탁원 API) 기반으로 교체

바로 위 항목("KIS는 실제 배당이 들어온다")을 확인한 뒤, "그럼 얼마·언제 들어왔는지"를
API로 정확히 조회하는 방법을 찾음. **KIS 예탁원정보(배당일정) API**
(`/uapi/domestic-stock/v1/ksdinfo/dividend`, TR_ID `HHKDB669102C0`, 파라미터: 종목코드
SHT_CD + 조회기간 F_DT/T_DT, 계좌 무관 — 종목 자체의 실제 배당 데이터)로 TIGER 배당커버드콜액티브의 실제
배당 기준일/주당배당금/지급일을 정확히 조회할 수 있음을 확인함(`kis_price_client.fetch_dividend_schedule`).
2026-07-31 기준일(주당 375원, 지급일 08-04)과 2026-08-31 기준일(주당 413원, 지급일
09-02) 두 건이 실제로 있었음 — **가족구성원B 실계좌의 배당입금내역 화면(지급일 2026-09-02,
세전=세후 비과세)으로 정확히 교차 검증됨.**

**조치**: `estimate_dividend.py`를 "연 15% 가정 월할" 어림값에서 이 실제 배당률 ×
기준일 시점 실제 보유수량 계산으로 전면 교체(KIS는 다시 켬 — krwProfit이 애초에
현금과 무관한 값이라 이중 계상 걱정은 기우였음, 정확한 실제 값이면 문제없음). 지급일
그대로(예: 09-02) 기록하고, 같은 계좌·같은 지급일 기록이 있으면 건너뛰어 중복 방지.
기존에 잘못 기록됐던 09-05분 어림값(KIS 3,014,281원/키움 1,731,871원)은 삭제하고
정확한 값으로 재기록함: KIS 08-04(1,718,250원)+09-02(4,121,740원), 키움
09-02(1,991,073원, 07-31 기준일 땐 아직 매수 전이라 그 배당은 대상 아님).
